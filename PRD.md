# PRD

## Goal
Provide engineering teams with a transparent view of project activity progress and schedule risk.

## Users
Project managers, planning engineers and project controls teams.

## MVP
1. View projects
2. View progress and delayed activities
3. Create projects and activities
4. Update activity progress
5. Predict delay risk
6. Display model metrics

## Success criteria
Progress is calculated from activity records, API workflows persist data, delay-risk predictions return probabilities and the dashboard is usable locally.

## Out of scope
Enterprise scheduling integration, cloud deployment and real project data.
